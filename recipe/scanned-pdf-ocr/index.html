Turn Scanned PDFs into Searchable Text

OCR a stack of scanned documents and feed the clean text into your agent for summarizing or filing.

#pdf#ocr#extraction#tesseract

What you need

  • Python 3.11+required
  • ocrmypdfrequired

Install the OCR toolchain

ocrmypdf wraps Tesseract and keeps your PDF layout. Install the language packs you need.

bash
pip install ocrmypdf
sudo apt install tesseract-ocr tesseract-ocr-eng tesseract-ocr-kor

OCR the document

Run it on a scan. The output looks identical but now has a text layer.

bash
ocrmypdf -l eng+kor input_scan.pdf output_searchable.pdf

Extract the text

Pull the text layer out with any PDF library, then hand it to your agent.

python
import pymupdf
doc = pymupdf.open("output_searchable.pdf")
text = "\n".join(page.get_text() for page in doc)

Ask your agent what you actually need

Summaries, action items, tables as CSV — extraction is the boring part, analysis is where the agent earns its keep.
